## 1. 这是什么

一套从高中电路基础出发、面向智能装备硬件工程的长期学习手册。目标不是替代教材，而是把“电路—器件—模拟/数字—传感—MCU—电机—电源—接口—PCB—测量—系统”组织成一条可实践的链路：

- 看懂原理图、Datasheet、参考设计；
- 设计传感器信号链、MCU 外围、电机驱动、电源与接口；
- 完成基础 PCB、测量、调试与故障定位；
- 把模块集成为可运行、可维护、可安全停机的智能装备。

全书 14 章、204 节；配套 10 个基础实验、6 个工程项目设计包、6 个工程案例、13 个 SPICE 网表、11 张图、7 份 BOM（6 完整 + 1 低功率）。

## 2. 快速开始（约 1 分钟）

1. **先读安全**：[安全与实践须知](安全与实践须知.md)（10 分钟，必须）。
2. **看路线**：[学习路线与能力地图](学习路线与能力地图.md)（S0–S6、门槛、实验/项目）。
3. **从基础开始**：[第 01 章](01_电路基础与电子学数学/01A_直流电路与动态分析.md) → 第 02 章 → 第 03/04 章。
4. **做实验**：[基础实验手册](12_智能装备综合硬件系统/实验/00_基础实验手册.md) 实验 1–5。
5. **进项目**：[项目总览](12_智能装备综合硬件系统/项目/00_项目总览.md)，从项目 1/2 开始。

> 不要先背完所有文档。按阶段推进，每章“手算→仿真→实测→记录”。

## 6. 版本与使用边界

| 项 | 状态 |
|---|---|
| 文档/章节 | 完成（v1.1.0） |
| 公式/设计计算 | 已做关键复核；未逐条外部验证 |
| 仿真 | 仅提供网表，**未运行** |
| PCB/Gerber | **未提供** |
| 打样/实测/EMC | **未完成** |
| 适用 | 长期学习、设计参考、课程/项目立项 |
| 不适用 | 直接投产、认证、替代原厂资料 |

**一句话**：可以拿来学和做设计，但不能把“文档里的目标值”当成“实测结果”。
