## 13.0 本章要解决的问题

你遇到一颗不认识的芯片、一个没做过的电路、一条看不懂的曲线。你需要：

1. 先查什么、后查什么？
2. 哪些资料可信、哪些只是二手转述？
3. Datasheet 几十页，怎么在 30 分钟内找到关键参数？
4. 应用笔记的“典型应用”为什么不能直接抄？
5. 怎么把资料、公式、术语整理成可复用的知识库？

本章是工具页，不追求理论完整；目标是把外部资料变成可追溯、可验证的工程依据。

## 13.1 资料分级与检索策略

| 等级 | 资料 | 可信度 | 用法 |
|---|---|---|---|
| 一手 | Datasheet、Reference Manual、Errata | 最高 | 参数/寄存器/限制 |
| 一手 | Application Note、Design Guide、Reference Design | 高 | 设计方法/布局/验证 |
| 一手 | 标准（IEC/ISO/IPC/GB） | 高 | 安规/EMC/测试 |
| 二手 | 教材、大学课程 | 高 | 系统学习 |
| 二手 | 厂商培训/白皮书 | 中高 | 选型/趋势 |
| 三手 | 博客、论坛、视频 | 中/低 | 找线索，回原文验证 |

检索顺序：

1. 器件型号 + `datasheet` / `reference manual`。
2. 器件型号 + `application note` / `layout guide` / `errata`。
3. 方案/拓扑 + `reference design` / `TIDA` / `EVAL`。
4. 标准编号 + 关键词。
5. 教材/课程补理论。

## 13.2 Datasheet 六步读法

1. **标题/状态**：型号、版本、日期、量产/停产、封装。
2. **绝对最大值**：超过会损坏，不能用于设计。
3. **推荐工作条件**：设计必须落在范围内。
4. **电气特性**：min/typ/max、测试条件（温度、电压、电流）。
5. **时序/曲线**：开关波形、降额曲线、典型应用。
6. **封装/热/布局**：θJA、焊盘、布局注意。

**参数陷阱**：

- 把 Absolute Maximum 当工作值。
- 忽略测试条件（$V_{GS}$、温度、负载）。
- 只看 typ 不看 max。
- 把“典型应用”当“推荐设计”。
- 忽略 Errata（硅片已知问题）。

## 13.3 Application Note 与参考设计

读法：

1. 先看“适用范围/限制”。
2. 看结论与推荐值。
3. 看推导/波形/测试条件。
4. 核对器件替代与版本。
5. 不照抄：输入/输出/负载/散热/安规可能不同。

**参考设计使用清单**：

- [ ] 输入/输出条件一致？
- [ ] 功率/电流/温度一致？
- [ ] 器件可采购/未停产？
- [ ] 变压器/电感可复制？
- [ ] 安规/EMC 已覆盖？
- [ ] 布局/热设计可落地？

## 13.6 符号、单位与量纲

| 量 | 符号 | 单位 |
|---|---|---|
| 电压 | $V,U$ | V |
| 电流 | $I,i$ | A |
| 电阻 | $R$ | Ω |
| 电容 | $C$ | F |
| 电感 | $L$ | H |
| 频率 | $f$ | Hz |
| 角频率 | $\omega$ | rad/s |

## 13.7 公式速查

| 公式 | 表达式 | 适用 |
|---|---|---|
| 欧姆定律 | $V=IR$ | 线性电阻 |
| 功率 | $P=VI=I^2R=V^2/R$ | 直流/有效值 |
| 分压 | $V_o=VR_2/(R_1+R_2)$ | 空载 |
| RC 截止 | $f_c=1/(2\pi RC)$ | 一阶 |
| RLC 谐振 | $f_0=1/(2\pi\sqrt{LC})$ | 串联/并联 |
| 阻抗 | $Z=R+j(\omega L-1/\omega C)$ | 正弦稳态 |
| 热噪声 | $e_n=\sqrt{4kTRB}$ | 电阻 |
| ADC LSB | $LSB=V_{FS}/2^N$ | 理想 |
| 信噪比 | $SNR=6.02N+1.76$ dB | 理想 ADC |
| 采样定理 | $f_s>2B$ | 无混叠 |
| 电机转矩 | $T=K_tI$ | 直流/BLDC |
| 反电动势 | $E=K_e\omega$ | 电机 |
| 导通损耗 | $P=I^2R$ | MOSFET |
| 开关损耗 | $P=0.5VI f(t_r+t_f)$ | 硬开关 |
| 结温 | $T_J=T_A+P\theta_{JA}$ | 热 |
| BUCK 占空比 | $D=V_o/V_i$ | CCM |
| 电感纹波 | $\Delta I=V_o(1-D)/(Lf)$ | BUCK |
| 目标阻抗 | $Z=V_{dd}\times ripple/\Delta I$ | PI |

## 13.8 选型速查

| 器件 | 先看 | 再看 |
|---|---|---|
| 运放 | 供电/输入共模/输出摆幅 | Vos、Ib、GBW、噪声、容性负载 |
| 仪表放大器 | 增益范围/共模范围 | CMRR、噪声、Vos、电源 |
| ADC | 分辨率/速率/接口 | ENOB、INL/DNL、基准、输入结构 |
| MOSFET | 耐压/电流 | Rds(on)@Vgs、Qg、SOA、热 |
| 栅极驱动 | 电压/电流 | 自举/隔离、死区、传播延迟 |
| 电源芯片 | 输入/输出/电流 | 频率、效率、保护、外围 |
| 接口芯片 | 电平/速率 | 共模、隔离、保护、终端 |
| 连接器 | 电流/针数 | 间距、锁扣、防护、寿命 |

## 13.10 资料更新与维护

- 每条资料记录：名称/机构/类型/版本/日期/链接/核查等级。
- 每 6 个月检查链接、器件状态、标准版本。
- 器件停产/替代：更新 BOM 与设计说明。
- 勘误：记录到版本记录，不静默修改结论。
- 个人知识库：按“章/主题/器件”建索引，保留原始链接与本地笔记。

## 本章小结

1. 一手资料优先；二手资料只用于学习和找线索。
2. Datasheet 先看绝对最大值/推荐条件，再看电气特性/曲线。
3. 参考设计要核对条件，不能照抄。
4. 标准是合规依据，不是“选读材料”。
5. 公式/术语/选型表要能快速检索，并带适用条件。
