## 1. 怎么读案例

每个案例按五个问题：

1. 为什么采用这种电路结构？
2. 关键器件怎么选？
3. 关键参数怎么定？
4. 哪里最容易忽略？
5. 改变输入/负载会怎样？

**注意**：案例是“设计对照”，不是让你照抄。抄之前必须核对输入/输出条件、器件替代、安规与布局。

## 2. STM32 官方开发板（Nucleo/Discovery）

**参考入口**：ST 官方开发板页面（[STM32 MCU Developer Zone](https://www.st.com.cn/content/st_com/zh/stm32-mcu-developer-zone.html)）。

**结构**：MCU + ST-Link/V2-1 + 5 V→3.3 V LDO + 晶振 + 复位按键 + BOOT 跳线 + Arduino/ST morpho 排针 + 用户 LED/按键。

**为什么**：

- 板载调试器，降低入门门槛。
- 5 V/3.3 V 多电源选择，排针兼容扩展板。
- 复位/BOOT/晶振按官方参考设计，减少“最小系统”踩坑。

**关键选型**：LDO 按调试器+MCU+扩展板电流选；晶振按 MCU 要求；排针按扩展板电平。

**容易忽略**：

- 调试器的 3.3 V 与目标板 3.3 V 可能“互相倒灌”，看跳线/电源选择。
- 扩展板大电流不能从板载 LDO 取。
- 排针地/电源顺序，插拔时先断电。

**改变条件**：接大电流外设 → 外部供电；高速 USB → 晶振/阻抗/ESD 更严。

> 核查等级：官方页面入口（L1/L2），未逐页核对具体板号原理图。

## 3. TI DRV8323 三相栅极驱动

**参考入口**：[TI DRV8323 产品页](https://www.ti.com.cn/product/cn/DRV8323)（含数据手册、布局/架构/FOC 应用笔记列表）。

**结构**：3 个半桥栅极驱动 + 电荷泵 + 低边线性稳压 + 可选 3 路电流采样放大器 + SPI/硬件接口 + 保护（UVLO/OCP/OTP/过流）。

**为什么**：

- 集成高边驱动（电荷泵）与保护，减少分立设计风险。
- 内置 CSA 简化相电流采样。
- 支持 6x/3x/1x PWM，适配不同 MCU 定时器。

**关键选型**：

- 母线电压 ≤60 V；峰值栅极电流 1 A/2 A。
- $Q_g$ 与 PWM 频率决定驱动损耗/温升。
- CSA 增益（5/10/20/40）与分流电阻匹配 ADC 范围。

**容易忽略**：

- 电荷泵/自举电容、VCP 电容按手册选。
- 功率地/采样地开尔文；CSA 输入共模范围。
- 死区/直通保护；栅极电阻与振铃。
- 保护阈值是“典型值”，批量要留裕量。

**改变条件**：更高母线 → 选 102 V 型号（DRV8353）；更大电流 → 外置 MOS/散热；更低噪声 → 外部 CSA/隔离。

> 核查等级：产品页与文档列表已读（L1）；具体应用笔记 PDF 未逐页读（L2）。

## 4. ST 电机控制 SDK 与 AN4144

**参考入口**：[UM2374（MC SDK v5.0）](https://www.st.com.cn/resource/en/user_manual/um2374-getting-started-with-stm32-motor-control-sdk-v50-stmicroelectronics.pdf)、[AN4144（有传感器 BLDC）](https://www.st.com.cn/resource/en/application_note/an4144-sensored-bldc-motor-control-with-stm32f10x-stmicroelectronics.pdf)。

**结构**：MCU + 三相逆变 + 栅极驱动 + 电流采样 + 霍尔/编码器 + 母线电容；SDK 负责 FOC/六步换相。

**为什么**：

- 硬件参考设计与软件库配套，缩短开发。
- 有传感器方案在低速/启动更可靠。

**关键参数**：

- PWM 频率、死区、电流采样时刻。
- 母线/分流/放大增益与 ADC 范围。
- 霍尔安装角度/相序。

**容易忽略**：

- 采样窗口与 PWM 对齐（下管导通时采）。
- 死区补偿与电流极性。
- 霍尔/编码器接线与软件相序不一致。

**改变条件**：无感 → 反电动势观测/启动策略；高压 → 隔离驱动/安规。

> 核查等级：ST PDF 链接可下载（L2），正文未逐页读。

## 5. ADI 数据采集与信号调理

**参考入口**：[Linear Circuit Design Handbook](https://www.analog.com/en/resources/technical-books/linear-circuit-design-handbook.html)、[Op Amp Applications Handbook](https://www.analog.com/en/resources/technical-books/op-amp-applications-handbook.html)、[Data Conversion Handbook](https://www.analog.com/en/resources/technical-books/data-conversion-handbook.html)。

**结构**：传感器 → 仪表放大 → 滤波 → ADC 驱动 → ADC → 基准/数字隔离。

**为什么**：

- 仪表放大提供高输入阻抗/CMRR；滤波限制噪声带宽；ADC 驱动解决采样电荷注入。
- 基准与 ADC 匹配决定有效位数。

**关键参数**：

- 增益、带宽、噪声、CMRR、Vos/Ib。
- ADC 采样时间/源阻抗/基准噪声。
- 布局：模拟分区、地平面、屏蔽。

**容易忽略**：

- 噪声增益（不是信号增益）决定输出噪声。
- 基准温漂/噪声被低估。
- ADC 驱动/RC 与采样时间不匹配。

**改变条件**：更高分辨率 → 更低噪声/更慢带宽/更好基准；更长线 → 隔离/屏蔽/共模。

> 核查等级：ADI 手册页面已读（L1），具体章节未逐页读。

## 6. Infineon 高边栅极驱动（AN-978）

**参考入口**：Infineon AN-978 *HV Floating MOS-Gate Driver ICs*（官方文档入口待补，L3）。

**结构**：浮动高边驱动 + 自举二极管/电容 + 电平移位/锁存 + 死区/保护。

**为什么**：

- 高边 NMOS 需要栅极高于源极；自举是低成本方案。
- 集成电平移位/驱动，减少分立器件。

**关键参数**：

- 自举电容/二极管耐压/恢复时间。
- 占空比限制（自举不能 100%）。
- dv/dt 抗扰/负压瞬变。

**容易忽略**：

- 自举电容在低频/长导通时掉压。
- 高边 dv/dt 通过米勒电容误导通。
- 自举二极管反向恢复/耐压。

**改变条件**：100% 占空比 → 电荷泵；高压 → 隔离驱动。

> 核查等级：L3，仅据行业通用原理与文档标题；具体参数需查原文。

## 7. 开源硬件：moteus / ODrive

**参考入口**：[moteus（GitCode 镜像）](https://gitcode.com/gh_mirrors/mo/moteus)、[ODrive（GitCode 镜像）](https://gitcode.com/gh_mirrors/od/ODrive)。

**结构**：STM32G4/STM32F4 + 三相逆变 + 栅极驱动 + 电流采样 + 编码器 + CAN/USB。

**为什么**：

- 开源、有原理图/PCB/固件/文档，适合研究“真实工程如何取舍”。
- 高功率密度、FOC、通信/调试完整。

**关键参数**：母线/相电流、MOSFET、分流/CSA、编码器接口、散热。

**容易忽略**：

- 开源项目的功率等级/安全边界；不能直接当低压教学板。
- 物料/版本/许可证；硬件文件可能在不同仓库/分支。
- 布局/热/EMC 是核心，不是“原理图对就行”。

**改变条件**：降功率 → 改 MOS/散热/采样；换电机 → 改编码器/参数。

> 核查等级：仓库元数据（许可证/语言/提交）已核对（L1）；**未逐文件核对原理图/PCB/BOM**（L3）。禁止把镜像页信息当完整设计验证。
