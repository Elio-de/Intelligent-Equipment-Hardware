---

## 1. 列定义

| 列 | 含义 |
|---|---|
| Ref | 位号（U/R/C/Q/J/F/D 等） |
| Value | 关键参数/型号（不是完整订货号） |
| Description | 器件类型/用途 |
| Package | 封装（需按实际库核对） |
| Qty | 数量（按单板） |
| Notes | 关键选型依据/注意事项（部分行是通用值） |

## 3. 未核查项

- 供货/库存/价格/交期。
- 替代料/停产风险。
- 完整订货号/封装库。
- 降额/热/EMC 实测。
- 具体 ILIM/补偿/栅极电阻的最终值（需按 Datasheet + 实测调整）。

---

## 4. 使用规则

1. 先按项目计算/正文确认参数，再查原厂 Datasheet。
2. 换型号必须重查引脚/封装/耐压/电流/热阻。
3. 关键器件（MOSFET/驱动/电源/隔离）必须做降额与热核算。
4. 采购前做供货/替代料核查；不要直接照 BOM 下单。
5. 低功率替代（P3/P6）使用单独 BOM，不要混用 24 V 完整版器件。
