## 3. 运行方法

### ngspice

```bash
cd 99_资源/仿真/01
ngspice -b rc_step.cir
```

交互模式：`ngspice rc_step.cir`，然后 `run`、`plot v(out)`。

### LTspice

`File → Open` 选择 `.cir` → `Run`。若报模型错误，检查 `.model` 行是否在网表内。

## 4. 依赖与已知限制

- `03/opamp_noninverting.cir` 用理想 E 源，**没有** GBW/失调/噪声/输出摆幅；不能用于真实运放验证。
- `03/comparator_hysteresis.cir` 用 `tanh` 行为源，非真实比较器延迟/失调。
- `02/mosfet_switch.cir` 用 Level 1 简化模型，未含 Qg/米勒/体二极管。
- `项目3_hbridge.cir` 用理想开关，未含死区/自举/寄生。
- `项目4_buck.cir` 用理想开关/二极管，未含 ESR/ESL/环路。
- 所有网表未做温度/蒙特卡洛/厂商模型对比。
