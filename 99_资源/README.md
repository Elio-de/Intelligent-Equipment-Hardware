# 资源目录

> 状态：目录已建立，内容待随正文逐步补充。

本目录存放不适合直接嵌入 Markdown 的文件：图片、仿真工程、测试数据、参考文档。所有资源必须能在正文中找到引用，且文件名可检索。

| 子目录 | 内容 | 命名约定 |
|---|---|---|
| [图片](图片/) | 重绘的原理图、波形、示意图 | `图章-序号_主题.png`，如 `图03-05_二阶低通.png` |
| [仿真](仿真/) | LTspice/ngspice/KiCad 仿真工程 | `章_主题.asc`，如 `01_rc_lowpass.asc` |

## 规则

1. 图片一律重绘，不直接截取厂商 Datasheet/教材原图；确需引用时注明来源与“重绘”。
2. 仿真文件保留模型、参数与运行说明，确保他人可复现。
3. 数据文件用 CSV，不用 Excel 二进制作为唯一副本；原始数据不覆盖，修订另存版本。
4. 参考文档只放允许再分发的资料；其余只记录链接与访问日期。
5. 单个文件建议 ≤10 MB；大文件放外部存储并在资料表登记。
