# 构建脚本

> 用途：从 Markdown 生成最终目录与 Word 阅读版；保留以便后续维护复现。

| 脚本 | 作用 | 运行 |
|---|---|---|
| `generate_toc.py` | 解析各章 `## x.y` 标题，生成根目录 `完整章节目录.md` | `python generate_toc.py` |
| `build_docx.py` | 将入口文档 + 章节 + 实验 + 项目 + 案例汇编为 `90_附录/交付/智能装备电子硬件学习手册_v1.1.docx` | `python build_docx.py` |

**注意**：

- 脚本内使用绝对路径 `C:\DeepSeek_ Project\智能装备电子硬件学习手册`；迁移目录后需改 `HB` 变量。
- Word 版是阅读汇编：公式以文本近似，表格/图片为简化排版；精确内容以 Markdown 为准。
- 重新生成前先备份/快照；生成后检查段落、表格、图片数量与目视排版。
