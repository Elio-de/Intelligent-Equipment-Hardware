## 编写要求

- 每条公式必须有：表达式、适用条件、符号与单位、一个数值例子、一个常见误用。
- 每张选型表必须有：参数窗口、测试条件、替代料、价格量级、停产风险。
- 每份检查清单必须可勾选，一项只检查一个点。
- 所有表格注明版本与复核人。
