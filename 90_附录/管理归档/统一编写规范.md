# 统一编写规范

> 文档编号：EHB-00-08  
> 版本：v0.1.0  
> 日期：2026-11-13  
> 状态：第一轮完成（规范 v1）  
> 适用范围：本手册所有章节、实验、项目文档、图表与引用

---

## 1. 目的

这部手册要长期维护、多人协作、反复修订。如果没有统一规范，三年后会出现：

- 同一概念三种译名，读者无法检索；
- 同一公式符号不同，推导接不上；
- 图表没有来源，无法判断可信度；
- 深度标记混乱，初学者不知道哪里可以跳过；
- 实验步骤缺少安全前提，读者照做会损坏器件或受伤。

本规范的目标是：**让任何一章由任何一位具备相应能力的作者来写，产出结构一致、证据充分、可复核、可教学。**

---

## 2. 文档元数据

每份文档（章、节、项目、附录）开头必须有：

```markdown
> 文档编号：EHB-03-02  
> 版本：v0.1.0  
> 日期：2026-11-13  
> 状态：草稿 / 技术复核 / 学习者试读 / 已发布  
> 深度：A/B/C/D（本章主深度）  
> 前置：第 01、02 章  
> 对应项目：P2  
> 作者/复核：——
```

规则：

- 文档编号：`EHB-章-节`，章两位、节两位；项目用 `EHB-P2`。
- 状态只能取上述五值之一，不允许“差不多完成”。
- 深度写本章/本节的主深度；混合深度在正文内标注。
- 前置必须能在《知识依赖关系》中找到对应节点。

---

## 3. 章节骨架

每章统一使用以下骨架，顺序不变；某节确实不需要某项时，写“本章不适用”，不要删掉标题造成结构不一致。

```markdown
# 第 03 章 模拟电子技术

## 3.0 本章要解决的工程问题
（一个真实场景 + 三个具体问题 + 本章边界）

## 3.1 学习目标与先修检查
（3–5 条可观察目标；5 条先修自检）

## 3.2 核心概念
### 3.2.1 ...
（概念 → 物理直觉 → 数学表达 → 典型值 → 常见误解）

## 3.3 公式、参数与工程判据
（公式表：表达式 / 适用条件 / 量纲 / 典型值 / 常见错误）

## 3.4 典型电路与设计流程
（从需求到参数，再到选型与仿真）

## 3.5 仿真与实验
（预测 → 搭建 → 测量 → 对照 → 差异解释）

## 3.6 常见错误与故障
（现象 / 可能原因 / 排查步骤 / 预防）

## 3.7 设计检查清单
（可勾选，≤15 项）

## 3.8 习题与项目任务
（A 级概念题、B 级设计题、C 级拓展题）

## 3.9 本章小结
（5 条以内，不重复目录）

## 3.10 参考资料
（REF 编号 + 具体章节/页码）
```

### 3.1 开头的“工程问题”

不要用“本章介绍……”开头。用一个具体场景，例如：

> 一只应变片的输出只有 2 mV/V 激励，桥臂电阻 350 Ω，你要把它接到 3.3 V、12 位 ADC 上，并保证 0.1% 的分辨率。直接接 ADC 会得到什么？为什么需要仪表放大？放大多少倍才不饱和？噪声从哪里来？

要求：

- 场景必须与智能装备相关（传感、电机、电源、接口、系统）。
- 给出具体数字，不用“很小/很大”。
- 结尾点明本章不解决什么，避免读者误以为学完就能做整机。

### 3.2 学习目标

用可观察动词：**能计算、能选择、能画出、能测量、能解释、能定位**。避免“了解、熟悉、掌握”这类无法验证的词。

反例：

- 了解运放的参数。

正例：

- 给定 GBW 与闭环增益，能计算闭环带宽，并说明为何大信号时还要检查压摆率。
- 给定 Vos 与增益，能计算输出失调，并判断是否满足 12 位 ADC 的 1 LSB 要求。

## 4. 深度标记与写法

### 4.1 标记位置

- 节标题末尾：`### 3.9 噪声与低噪声设计 [B]`
- 段落级：在段首用 `【C】` 标记拓展段，并在段末给“可跳过”提示。
- 公式/表格：在标题后标注 `[B]`。

### 4.2 不同深度的写法

| 深度 | 必须包含 | 不应包含 | 篇幅建议 |
|---|---|---|---|
| A | 物理直觉、定义、公式、典型值、1 个例题、3 道练习 | 长篇推导、厂商选型细节 | 800–1500 字 |
| B | 设计流程、参数表、选型判据、仿真、实测、验收指标 | 纯理论证明、无关历史 | 1500–3000 字 |
| C | 核心方程、适用条件、文献指引、一个工程案例 | 完整推导、代码级实现 | 800–1500 字 |
| D | 一段说明 + 权威链接 + 何时需要 | 任何展开 | ≤300 字 |

### 4.3 “可跳过”块

C/D 内容前统一加：

```markdown
> **可跳过**：本节属于进阶理解，不影响后续项目；首次阅读可只记住“有这件事、需要时查 REF-XX”。
```

### 4.4 不允许的写法

- 用“显然”“容易看出”代替推导。
- 把厂商 Typical Application 直接当推荐设计。
- 只给结论不给测试条件。
- 用“高精度”“高性能”而不给数字。
- 把 C 级内容写成必读，制造焦虑。

## 5. 数学、单位与符号

### 5.1 基本规则

| 项 | 规则 | 示例 |
|---|---|---|
| 变量 | 斜体 | $V_{out}$、$I_{ds}$、$f_c$ |
| 单位 | 正体，与数值间一个空格 | 5 V、10 kΩ、100 nF、3.3 V |
| 量纲 | 公式必须量纲一致 | $RC$ 的单位是秒 |
| 数值 | 小数点前保留 0 | 0.1，不写 .1 |
| 范围 | 用“–”连接，单位只写一次 | 0–100 °C、-40–85 °C |
| 公差 | ± 后给单位 | ±1%、±5 mV |
| 分贝 | 电压用 20log，功率用 10log | $20\log_{10}(V_2/V_1)$ |
| 温度 | 数字与 °C 间空格 | 25 °C |
| 频率 | Hz/kHz/MHz，不用 c/s | 20 kHz |

### 5.2 易错符号

- mΩ（毫欧）与 MΩ（兆欧）必须写清。
- μ 与 u：正文用 μ，代码/文件名可用 u。
- 下标：$R_{ds(on)}$、$V_{CE(sat)}$、$Q_g$；不要用中文下标。
- 相量：$\dot{V}$ 或 $\mathbf{V}$，全文统一。
- 复阻抗：$Z = R + jX$，不要用 $i$（避免与电流混淆）。

### 5.3 公式块

```markdown
$$
f_c = \frac{1}{2\pi RC}
\tag{3-1}
$$

其中 $R$ 为反馈电阻（Ω），$C$ 为反馈电容（F）。适用条件：理想运放、单极点近似。
```

每个公式必须给出：

1. 适用条件；
2. 各符号含义与单位；
3. 一个数值例子；
4. 一个常见误用。

## 6. 电路图与原理图规范

### 6.1 位号

| 器件 | 位号 | 示例 |
|---|---|---|
| 电阻 | R | R1、R2 |
| 电容 | C | C1、C2 |
| 电感 | L | L1 |
| 二极管 | D | D1 |
| 晶体管 | Q | Q1 |
| 集成电路 | U | U1 |
| 连接器 | J | J1 |
| 开关 | SW | SW1 |
| 保险丝 | F | F1 |
| 测试点 | TP | TP1 |
| 晶振 | Y | Y1 |

### 6.2 网络命名

- 电源：`+3V3`、`+5V`、`+24V`、`VBUS`、`VCC`。
- 地：`GND`、`AGND`、`PGND`、`CHASSIS`；必须说明连接关系。
- 信号：大写 + 下划线，如 `MOTOR_A`、`ENC_A+`、`CAN_H`。
- 低有效信号：前缀 `n` 或后缀 `_N`，如 `nFAULT`、`RESET_N`；全文统一。
- 差分对：`+`/`-` 或 `_P`/`_N`，全文统一。

### 6.3 元件标注

原理图/图表中的元件至少标注：

- 数值 + 单位（4.7 kΩ）；
- 精度/耐压/介质（±1%、50 V、X7R、C0G）；
- 关键器件标注封装或型号。

### 6.4 图的要求

- 每张图有图号与标题：`图 3-5 二阶 Sallen-Key 低通`。
- 图下注明来源：`来源：作者绘制` 或 `来源：REF-A02, Fig. 4-3，重绘`。
- 图中所有节点、电源、地、参考方向清晰；不留悬空网络。
- 测量图必须标注探头位置、量程、带宽限制。
- 不使用厂商原图直接截图；需要时重绘并注明“依据 REF-XX 重绘”。

### 6.5 波形图

- 横轴/纵轴必须带单位与量程。
- 标注关键点：峰值、纹波、上升沿、振铃频率。
- 同时给出时间基准与探头衰减（如 10 µs/div，×10）。
- 不裁剪掉地参考与触发点。

## 7. 表格、代码与公式排版

### 7.1 表格

- 表头必须有单位；单位不重复写在单元格里。
- 每张表有表号与标题：`表 5-2 电桥误差源`。
- 数值对齐；缺数据写“—”，不写“无”。
- 表格下方注明数据来源与测试条件。

### 7.2 代码

- 代码块标注语言：`c`、`python`、`bash`、`text`。
- 只给验证硬件所需的最小代码；完整工程放 `99_资源`。
- 寄存器/引脚名用代码格式：`PA0`、`TIM1_CH1`、`ADC1_IN5`。
- 代码注释解释“为什么”，不解释“是什么”。

### 7.3 清单

- 使用 `- [ ]`，每项可验证。
- 一项只检查一个点；不写“检查电路是否正常”。
- 例：`- [ ] 3.3 V 输出在空载与 100 mA 负载下均在 3.20–3.40 V`。

## 8. 术语与中英对照

### 8.1 首次出现

格式：中文（English，缩写）。例：

> 运算放大器（operational amplifier, op amp）的增益带宽积（gain-bandwidth product, GBW）……

后文只用中文或通用缩写；不要中英混用到读者不知道指哪个。

### 8.2 统一译名（节选）

| 英文 | 统一中文 | 不用 |
|---|---|---|
| op amp | 运算放大器 / 运放 |  Op 放大器 |
| gate driver | 栅极驱动器 | 门驱动器 |
| decoupling | 去耦 | 退耦 |
| bypass | 旁路 | 去耦（混用） |
| return path | 回流路径 | 回程 |
| ground plane | 地平面 | 接地层（可混用，首次注明） |
| common-mode | 共模 | 同相（混用） |
| differential | 差分 | 差动（可混用，统一） |
| duty cycle | 占空比 | 负载比 |
| dead time | 死区时间 | 死区 |
| bootstrap | 自举 |  bootstrap |
| flyback | 续流 / 反激（按语境） | 飞返 |
| isolated | 隔离 | 绝缘（混用） |
| pull-up | 上拉 | 拉起 |
| worst case | 最坏情况 | 最差 |
| derating | 降额 | 减额 |
| form factor | 封装形式 / 外形 | 形状因子 |

> “flyback”有两个含义：电路中的续流二极管路径，和反激拓扑。正文必须写“续流”或“反激”，不要只写 flyback。

### 8.3 缩写

首次出现给全称；全文统一大小写：

- MCU、ADC、DAC、PWM、EMC、ESD、TVS、LDO、BUCK、FOC、ICD、BOM、DFM、DFT。
- 不写“mcu”“Adc”。

## 9. 引用与版权

### 9.1 引用格式

正文：

> 根据 REF-A02 第 4 章，仪表放大器的共模抑制比会随增益变化……

文末：

```markdown
## 参考资料
- [REF-A02] Analog Devices. *Op Amp Applications Handbook*. 2005. https://www.analog.com/...（访问 2026-11-13）
```

规则：

- 引用具体章节/图表/页码，不只给整本书。
- Datasheet 引用必须带 Revision 与日期。
- 网页引用带访问日期。
- 同一资料全文用同一编号。

### 9.2 版权

- 不直接复制厂商图表、课程讲义、教材插图；需要时重绘并注明“依据……重绘”。
- 引用文字单段不超过 50 字，且必须标注来源；长段改写并给引用。
- 开源硬件项目的原理图/PCB 遵循其许可证（MIT/Apache/CERN-OHL/CC-BY-SA）；商用前单独核对。
- 标准文本不复制；只引用编号、适用范围与关键判据。

### 9.3 事实、经验、建议、风险

正文用四种标记区分信息性质：

- `【事实】` 有文献/数据支持。
- `【经验】` 工程实践总结，注明适用条件。
- `【建议】` 作者推荐，允许有不同做法。
- `【风险】` 可能导致损坏/伤害/认证失败。

例：

> 【经验】在 24 V/5 A 的电机驱动板上，把电流采样电阻的地与功率地单点连接，通常比大面积铺铜更不容易引入开关噪声；但具体取决于布局，需用示波器验证。

## 10. 写作风格

### 10.1 语气

- 用“你”称呼学习者；用“我们”描述共同步骤；不用“笔者”。
- 句子短，一段一个意思；技术名词先定义后使用。
- 不用营销词：“强大、完美、极致、革命性”。
- 不用恐吓式表达：“不学这个就完了”。
- 允许说“这里有个坑”，但必须紧跟“为什么”和“怎么避免”。

### 10.2 结构

每个小节尽量遵循：

1. **问题**：为什么需要它？
2. **直觉**：用图/类比建立物理图像。
3. **定量**：公式、参数、典型值。
4. **边界**：什么时候不适用？
5. **验证**：怎么测/怎么仿真？
6. **自检**：3 个问题。

### 10.3 例题

每个 B 级知识点至少 1 个完整例题，按“已知→求→解→验算→讨论”写。验算必须包含量纲或数量级检查。

### 10.4 习题

- A 级：概念解释、简单计算（3–5 题）。
- B 级：设计/选型/调试（1–2 题，带指标）。
- C 级：阅读应用笔记并复现（1 题，带来源）。
- 不给“查资料写一篇”的空泛题。

## 11. 安全与实验规范

### 11.1 每章实验开头必须写

```markdown
> **安全等级**：低压（≤24 V）/ 中压（24–48 V）/ 需监护  
> **最大电流**：___ A  
> **必需防护**：护目镜 / 绝缘手套 / 灭火器 / 监护人在场  
> **禁止事项**：带电改线 / 短路测试 / 超过 ___ V
```

### 11.2 实验步骤

- 先断电接线，检查后再上电。
- 首次上电必须限流；写明限流值。
- 母线电容必须写放电方法与等待时间。
- 电机必须固定、加防护；写明“先低速”。
- 电池必须写型号、保护板、充电监护。
- 任何“可能冒烟/起火”的步骤，必须给出应急处理。

### 11.3 禁止写入正文的操作

- 220 V 市电直接操作。
- 绕过保险丝/急停/保护板。
- 用万用表电流档测电源电压。
- 带电插拔功率连接器。
- 无监护的高压/大电流/高转速实验。

## 13. 评审流程

| 阶段 | 负责人 | 检查内容 | 产出 |
|---|---|---|---|
| 1. 自检 | 作者 | 第 12 节清单 | 自检表 |
| 2. 技术复核 | 同领域工程师/教师 | 正确性、边界、数据 | 复核意见 |
| 3. 学习者试读 | 1–2 名目标读者 | 能否看懂、哪里卡住 | 试读记录 |
| 4. 编辑 | 编辑/作者 | 语言、格式、引用 | 终稿 |
| 5. 发布 | 项目负责人 | 版本、目录、链接 | 发布记录 |

规则：

- 技术复核不通过，不进入试读。
- 试读中超过 2 人同一处卡住，必须改写。
- 任何“事实”类错误，必须回溯到源头并更新资料表。

## 14. 版本与变更

### 14.1 版本号

- `v0.x.y`：草稿/未完成；x 为结构变更，y 为文字修订。
- `v1.0.0`：首版完整发布。
- `v1.x.0`：新增章节/项目。
- `v2.0.0`：知识体系或目录结构重大调整。

## 15. 文件命名与目录

### 15.1 章节文件

```text
01_电路基础与电子学数学/
├─ README.md
├─ 01_01_电路变量与参考方向.md
├─ 01_02_基尔霍夫定律与电阻网络.md
└─ ...
```

规则：

- `章号_节号_节标题.md`，下划线分隔，不用空格。
- 一节一文件；超过 8000 字的节拆成 `01_02a_...`、`01_02b_...`。
- 章目录的 `README.md` 放本章状态、节列表、项目、资料索引。

### 15.2 资源文件

```text
99_资源/
├─ 图片/01/图01-03_戴维南等效.png
├─ 仿真/01/rc_lowpass.asc
├─ 数据/03/ina333_gain.csv
└─ 参考文档/README.md
```

规则：

- 图片按章分目录；文件名含图号与主题。
- 仿真文件与章节节号对应；保留模型与参数。
- 数据文件用 CSV，首行写单位；不要用 Excel 二进制作为唯一副本。
- 参考文档只放有版权许可的文件；其余记录链接。

### 15.3 命名禁用

- 空格、`#`、`?`、`*`、`|`、`<`、`>`。
- “最终版”“最新”“副本”“新建文件夹”。
- 纯日期文件名（无法检索内容）。

## 16. 一页纸总结

1. 每章先给工程问题，再给知识；不要从定义开始。
2. 每个 B 级结论必须有计算/仿真/实测之一。
3. 每个公式有适用条件、单位、例子、误用。
4. 每张图有编号、来源、测试条件。
5. 每个 C/D 内容有“可跳过”，不绑架初学者。
6. 每个实验有安全等级、限流值、禁止事项。
7. 每个术语首次出现给中英全称，全文统一。
8. 每个引用可追溯到版本/日期/章节。
9. 每个项目有验收指标，不接受“亮了就行”。
10. 每个版本有变更记录，不覆盖历史。
