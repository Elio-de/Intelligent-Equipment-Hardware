## 1. 项目章程

### 1.1 项目名称

《智能装备与系统专业电子硬件知识学习手册》（以下简称“本手册”）。

### 1.2 项目目标

为具备高中电路基础、正在学习 C 与 STM32 的智能装备与系统专业本科生，建立一套从电路基础到整机系统的电子硬件学习体系，使其在 16–18 个月内逐步具备：

1. 理解元器件与电路；
2. 阅读原理图、Datasheet 与参考设计；
3. 设计传感器信号链与 MCU 控制板；
4. 理解并实现电机驱动、电源与工业接口；
5. 完成 PCB、测量、调试与故障定位；
6. 整合为可运行、可维护、可安全停机的智能装备。

### 1.3 交付形态

- Markdown 为主源，按章分目录、按节分文件。
- 图表使用 Mermaid 或重绘图片；仿真文件、测试数据、模板放资源目录。
- 所有引用可追溯到原始资料与版本。

### 1.4 非目标

- 不替代学校教材，不承诺考试提分。
- 不培养 IC 设计、射频前端、机械结构设计能力。
- 不做高压市电、大容量电池组、高功率电机的初学者实物项目。
- 不承诺就业与薪资结果。

## 2. 范围与边界

### 2.1 范围内

| 类别 | 内容 |
|---|---|
| 知识 | 电路、器件、模拟、数字、传感、MCU、电机、电源、接口、PCB/EMC、测量、系统 |
| 实践 | P0–P9 共 10 个项目（含准备） |
| 文档 | 9 份规划文档、14 章正文、附录、实验手册、故障库 |
| 资源 | 图表、仿真、数据、模板、参考资料表 |

### 2.2 范围外

- 具体企业的产品设计资料（保密）。
- 需要专业认证的高压/大功率/医疗/汽车功能安全实物设计。
- 完整的 EDA 软件教程（只给流程与检查表）。
- 完整的嵌入式软件课程（只讲硬件接口与 bring-up）。

### 2.3 安全边界

- 所有实物项目 ≤48 V DC、≤5 A、≤150 W。
- 市电电源只做原理与安规认知，不做实物。
- 锂电池只用成品带保护板电池组，充电有人值守。
- 任何项目必须有保险丝、限流、急停或断电手段。

## 12. 变更管理

### 12.1 变更类型

| 类型 | 例子 | 审批 |
|---|---|---|
| 文字修订 | 错别字、语句 | 作者自审 |
| 节内调整 | 增删小节、换例题 | 章节负责人 |
| 章级调整 | 新增/合并章 | 项目负责人 + 依赖复核 |
| 体系调整 | 改深度比例、改路线 | 项目负责人 + 全体复核 |

### 12.2 变更流程

1. 提出变更（原因、影响范围、替代方案）。
2. 检查是否破坏依赖关系与学时平衡。
3. 更新目录、资料表、项目映射。
4. 在本文档“版本记录”登记。
5. 通知相关章节作者。

### 12.3 禁止的变更

- 未经复核删除安全警告。
- 为赶进度跳过技术复核。
- 把 L3 资料当唯一依据写入正文。
- 改变章序但不更新依赖图。
